# Terms of Use for the Neo Angband Bug Fixes Mod

Effective date: 2026-08-23.

Bug Fixes is an optional Neo Angband mod folder, not a separate hosted service. It offers named, optional fixes for behavior inherited from Angband 4.2.6. The mod is disabled until installed and enabled, and its fix categories can be changed in the mod controls. Disabling it restores the base game's corresponding behavior.

The mod can change text, history, state persistence, object ordering, and dungeon-level layout. Its level-generation fix can alter a generated level by adding a reachable replacement staircase. A character played with gameplay-affecting fixes is marked outside the unmodified score comparison. A player remains responsible for deciding whether to use the mod with a particular character and for retaining an export or backup of local saves.

The examined shipped manifest does not declare network access, and the examined shipped plugin code does not make network requests. GitHub retrieval during an in-game installation or mod update is performed by the Neo Angband host, not by this mod as an independent service.
