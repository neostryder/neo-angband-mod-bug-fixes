# Terms of Use for the Neo Angband Bug Fixes Mod

Effective date: 2026-08-23.

Bug Fixes is an optional mod folder that runs inside Neo Angband, with no separate hosted service. It offers named, optional fixes for behavior inherited from Angband 4.2.6. The mod is disabled until installed and enabled, its fix categories can be changed in the mod controls, and disabling it restores the base game's corresponding behavior.

The mod can change text, history, state persistence, object ordering, and dungeon-level layout. Its level-generation fix can alter a generated level by adding a reachable replacement staircase. A character played with gameplay-affecting fixes is marked as outside the unmodified score comparison. The player is responsible for deciding whether to use the mod with a particular character and for keeping an export or backup of local saves.

Its shipped manifest does not declare network access, and its shipped plugin code makes no network requests. Installing or updating it from the in-game mod manager can still fetch its public files from GitHub; those requests come from the Neo Angband host's mod manager. The core Neo Angband Terms and Privacy Policy cover that shared host behavior, including local storage, update checks, and the risks of optional third-party mods.
